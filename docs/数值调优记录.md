# 数值调优记录（P7）

> 目的：把 P6 遗留的两个平衡问题修掉——① 终局等级 Lv6，与 GDD「第3章 Lv10~13」不符；
> ② Boss 战 2~4 回合、最低血线 100%/53%，不是「节奏高点」。
> 方法：**只改 CSV 数据，不改代码**（数据驱动原则），用 `tests/sim_campaign.tscn` 自动通关模拟做迭代证据。

## 度量口径

- 模拟脚本：`tests/sim_campaign.tscn`（固定随机种子 `seed(20261011)`，结果可复现）。
- 玩家策略为「简单 AI 基线」：队友半血以下治疗、否则放第一个能放的伤害/增益技能、没蓝普攻；
  **不买装备、不用道具** = 强度下限。真人玩家有装备+道具+元素克制，实际体验只会比模拟宽裕。
- 每场战斗记录三个指标：**回合数**（节奏）、**最低血线**（全队任意成员历史最低 HP%，= 紧张度）、**死亡数**（挫败风险）。
- 设计目标带：教学/第1章 1~2 回合满血（上手期）→ 第2章杂兵 3~4 回合、血线 60~85% → 中 Boss 4~6 回合、血线 40~65% → 中 Boss 后 1 场冷却爽局 → 第3章杂兵 4~5 回合、血线 45~70% → 最终 Boss 8~12 回合、血线 20~45%（全游戏最接近死亡的一战）。

## 迭代过程

**v1（经验重分配 + 全敌强化）**：按「章节爬坡、Boss 跳级奖励」重排 exp_reward（slime 60 / bat 180 / turret 200 / drone 300 / hound 400 / warden 1500 / shade 550 / crystal 650 / core 3600），金币约 ×2.7；敌人血量/攻击整体上调（warden 280→520 HP、core 650→1400 HP）。
结果：终局 Lv10 达标；最终 Boss 9 回合/血线 20% 达标；但第2、3章杂兵仍 2 回合/93~100% 血线——爬坡段没有紧张感。

**v2（杂兵爬坡段补强）**：drone 150→190 HP、atk 28→34；hound 170→210、atk 36→42；shade 220→300、atk 44→52；crystal 260→340、matk 48→56；core 经验 3600→4000（让终局落 Lv11 而非贴 Lv10 下限）。
结果：杂兵战进入 3~4 回合/49~71% 血线；但最终 Boss 因随机序列偏移变成 7 回合/50%——比中 Boss 的「高点感」不够突出。

**v3（Boss 高点再强调，采纳）**：warden 520→620 HP、atk 48→54；core 1400→1600 HP、atk 60→66、matk 66→72。
结果：中 Boss 4 回合/61%，最终 Boss 9 回合/31%——最终 Boss 重新成为全游戏回合最长、血线最低的一战。

## 经验与经济的分配逻辑

- 经验按「战斗重要性」分配而非按敌人数量平均：教学 60 → 第1章 240/380 → 第2章 700/700 → 中 Boss 1500 → 第3章 1200 → 最终 Boss 4000。Boss 经验 ≈ 同章杂兵战 2~3 倍，让「打赢高点」有明确的成长反馈。
- 累计经验 201+8380+400=8981 → Lv11（Lv12 需 10992），给「刷支线/复战」留出升级空间而不溢出。
- 金币总收入 2870：全套毕业装备约 3400（三人），**买不齐** → 商店选择有取舍；消耗品 30~150/个，保证「道具指令」有经济压力（见 P7b）。

## 遗留与后续

- 模拟死亡数恒为 0：简单 AI 治疗保守且种子固定；真人操作方差更大，属预期。若试玩反馈「最终 Boss 太难/太易」，优先调 core 的 atk/matk（±10%）而非血量。
- 元素克制的策略价值未量化（1.5 倍系数是否够显著），留给真人试玩反馈后在 P8 前微调。
