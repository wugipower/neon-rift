## 核心公式

### 属性派生（角色，随等级变化）

一级属性随等级成长：`属性(Lv) = base + grow * (Lv - 1)`

```
HP上限 = 100 + VIT*12 + Lv*5
MP上限 = 30  + INT*6  + Lv*2
物理攻击 ATK = 8 + STR*2.0
异能攻击 MATK = 8 + INT*2.0
防御 DEF = 5 + VIT*1.0 + Lv*0.5
速度 SPD = 8 + AGI*1.5
暴击率 CRT = min(50%, 5% + AGI*0.3%)
闪避率 EVA = min(25%, 3% + AGI*0.2%)
```

敌人属性直接读 `enemies.csv` 的固定值，不走派生（便于手工精调每场战斗）。

### 伤害公式（护甲递减减伤）

```
减伤率 = DEF / (DEF + K)，K = 100 + 10 * 攻击方等级
基础伤害 = 技能power * 攻击属性（physical用ATK，magic用MATK，heal用MATK）
最终伤害 = 基础伤害 * (1 - 减伤率) * 元素系数 * 随机(0.95~1.05) * 暴击倍率
最低伤害 = 1
暴击倍率 = 1.5（可被装备/技能提升）
命中率 = clamp(50%, 100% + 攻方命中 - 守方闪避, 100%)
```

**为什么用递减减伤**：线性相减（ATK-DEF）在高防御时会出现零伤害或收益爆炸；
`DEF/(DEF+K)` 让每点防御边际收益平滑递减，且 K 随等级增长，保证高等级战斗仍需堆攻击，便于控制数值膨胀。

### 经验曲线

```
升到下一级所需 EXP = floor(50 * Lv^1.6)
```
`levels.csv` 已预算好 1~20 级数值。曲线前松后紧：早期快速升级建立正反馈，
后期升级变慢，配合关卡敌人 exp_reward 控制「几场战斗升一级」的节奏。

## 词汇表（代码按这些 id 解析）

### damage_type（技能伤害类型）
- `physical`：用 ATK 结算
- `magic`：用 MATK 结算
- `heal`：治疗量 = power * MATK
- `buff` / `debuff`：无直接伤害，施加状态

### target（目标，相对施法者）
- `enemy_one` / `enemy_all`：单个 / 全体敌方
- `ally_one` / `ally_all`：单个 / 全体己方
- `self`：自身

### effect（状态效果 id）
| id | 效果 |
|---|---|
| `none` | 无 |
| `shock` | 感电：每回合有概率跳过行动 |
| `freeze` | 冰冻：速度下降 |
| `burn` | 灼烧：每回合损失生命（DoT） |
| `atk_up` / `def_up` | 攻击 / 防御提升 |
| `regen` | 每回合回复生命（HoT） |
| `shield` | 护盾，吸收一定伤害后消失 |

`effect_chance` = 施加概率（0~1），`effect_turns` = 持续回合。

### condition（敌人 AI 触发条件）
| id | 含义 |
|---|---|
| `always` | 始终可用 |
| `hp_below_50` | 自身血量低于 50% |
| `hp_below_30` | 自身血量低于 30% |
| `ally_hp_below_50` | 有同伴血量低于 50%（用于治疗） |

**AI 决策流程**：筛出满足 condition 的候选技能 → 按 weight 加权随机选一个。

### element（元素）
`电 / 水 / 火 / 冰 / 无`。克制环：`电→水→火→冰→电`（克制 1.5，被克 0.75，`无`恒为 1.0）。

## 角色与队伍定位

| 角色 | 元素 | 定位 | 设计意图 |
|---|---|---|---|
| 凛 | 电 | 均衡输出 | 全能主力，群体+单体+自增益，适合新手上手 |
| 苍 | 冰 | 坦克前排 | 高体质高防御，冰冻控制 + 护盾，扛伤害 |
| 澪 | 水 | 灵能辅助 | 高灵能，单体治疗 + 群体回春 + 高倍率法伤 |

三人队伍覆盖「输出/生存/续航」经典铁三角，能演示队伍构成与配合的设计思考。

## 关卡敌人分布（对应方案第 6 节）

| 章节 | 敌人 | 等级段 |
|---|---|---|
| 第1章 废弃地铁站 | e_slime / e_bat / e_turret | Lv3~5 |
| 第2章 商业区屋顶 | e_drone / e_hound / **e_warden(中Boss)** | Lv6~9 |
| 第3章 裂隙核心 | e_shade / e_crystal / **e_rift_core(最终Boss)** | Lv10~13 |

Boss 多阶段通过 AI 条件实现：如 e_warden 血量低于 50% 后解锁 `e_frost_nova`（群体）+ `e_enrage`（狂暴），制造节奏高点。
